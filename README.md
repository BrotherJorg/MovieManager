# MovieOwl - A Simple Movie Manager

## Description

MovieOwl is a desktop application built using Python, SQLite, and PyQt, which provides the user with a way to manage their personal collection of movies through a Graphical User Interface.

This program allows for creating, editing, searching, filtering, and creating collections of movies.
The user can also access a simple review and notes system, with additional support for movie recommendations through a scoring system and random selection.
Finally, a dashboard is present for simplified readings of collection statistics.

Personal management of a collection gets harder the bigger it grows. It can be hard to know what you own and keep track of movies in a collection, the watch status, the reviews, the ratings, and personal notes, especially when this information is scattered across platforms or written manually.

MovieOwl solves this problem by providing an intuitive management environment that allows user management of creating the collection, editing it, searching, filtering, and logging movies.
It also provides a rating and review system as well as a recommendation system, all in one desktop environment.
