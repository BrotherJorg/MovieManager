# MovieOwl - A simple movie manager
## Description
  MovieOwl is a desktop application built using python, SQLlite and pyQt. 
  The software provides the user a way to manage their personal collection of movies through a Graphical User Interface.

  The application provides the user the ability to create movie records, edit those records, search and filter their collection for specific genre.
  and manage watch status. This program also provides a rating, review and notes system as well as a recommendations and random movie selection.
  Finally the user has accesss to a simplified dashboard for a short statistics of their collection.
