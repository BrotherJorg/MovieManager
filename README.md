# MovieOwl - A simple movie manager
## Description
  MovieOwl is a desktop application built using python, SQLlite and pyQt. Which provides the user a way to manage their personal collection of movies through a Graphical User Interface.

  This program allows for creating, editing , searching, filtering and creating collections of movies. 
  The user can also access a simple review and notes system, with additional support for movie recommendation through a scoring system and random selection.
  Finally a dashboard is present for simplified readings of collection statistics.
